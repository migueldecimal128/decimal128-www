Decimal128 is available as a native implementation in eight languages, plus a
Python wrapper over the C core. Each port lives in its own repository on GitHub.
Swift is the reference implementation the other ports are validated against.

## Native ports

- **[decimal128-swift ↗](https://github.com/migueldecimal128/decimal128-swift)** — the reference implementation (SwiftPM).
- **[decimal128-c ↗](https://github.com/migueldecimal128/decimal128-c)** — C core (CMake + ctest).
- **[decimal128-csharp ↗](https://github.com/migueldecimal128/decimal128-csharp)** — native .NET (System.UInt128).
- **[decimal128-java ↗](https://github.com/migueldecimal128/decimal128-java)** — JVM core (Gradle).
- **[decimal128-kotlin ↗](https://github.com/migueldecimal128/decimal128-kotlin)** — Kotlin Multiplatform (JVM + native).
- **[decimal128-rust ↗](https://github.com/migueldecimal128/decimal128-rust)** — native Rust (single crate, native u128).
- **[decimal128-go ↗](https://github.com/migueldecimal128/decimal128-go)** — native Go.
- **[decimal128-zig ↗](https://github.com/migueldecimal128/decimal128-zig)** — native Zig (native u128 and u256).

## Python

- **[decimal128-python ↗](https://github.com/migueldecimal128/decimal128-python)** — a hand-written CPython extension over the vendored C core.
